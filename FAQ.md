## FAQ по Telegram‑боту CLI_SORT

- **Что делает этот бот?**  
  CLI_SORT — это Telegram‑бот для сравнения различных алгоритмов сортировки на одном и том же массиве. Бот показывает время работы выбранного алгоритма и сравнивает его с встроенной сортировкой Python.

- **Как быстро получить ответы на частые вопросы?**  
  Отправьте команду `/faq` в чате с ботом — он вернёт краткую подборку самых частых вопросов и ответов. Более подробная и техническая информация находится в этом файле `FAQ.md` в репозитории проекта.


- **Как задать массив для сортировки через бота?**  
  Типичный сценарий:
  - отправьте боту команду `/start`;  
  - следуйте подсказкам бота: либо пришлите массив чисел через пробел в одном сообщении, либо укажите границы и размер для генерации случайного массива (в зависимости от реализованного интерфейса команд).

- **Какие алгоритмы сортировки поддерживаются?**  
  В проекте реализованы и доступны через меню следующие алгоритмы (список может расширяться):

  - bubble sort  
  - radix sort  
  - bucket sort  
  - counting sort  
  - heap sort  
  - insertion sort  
  - shell sort  
  - quick sort  
  - merge sort

- **Почему иногда некоторые сортировки недоступны?**  
  Для массивов, содержащих отрицательные числа, алгоритмы `counting sort` и `bucket sort` отключаются, так как их реализация рассчитана на неотрицательные значения.

- **Что именно делает бот при сортировке?**  
  Для выбранного алгоритма бот:

  - копирует исходный массив и сортирует его выбранным алгоритмом, замеряя время работы;  
  - отдельно сортирует исходный массив встроенной функцией `sorted`, также замеряя время;  
  - сравнивает результаты (для большинства алгоритмов) и выводит оба времени и итоговый отсортированный массив.

- **Что делать после одной сортировки?**  
  После завершения сортировки бот может предложить:

  - отсортировать тот же массив другим алгоритмом;  
  - отправить новый массив или параметры генерации;  
  - прекратить взаимодействие (просто перестать отправлять команды).

- **Почему я получаю ошибку "введите числа через пробел, без скобок."?**  
  Это означает, что при вводе массива были использованы недопустимые символы. Убедитесь, что вводите только целые числа, разделённые пробелом, без запятых и скобок.

- **Почему говорится, что массив не может быть пустым?**  
  Если вы ничего не ввели или задали количество элементов генератора равным нулю, массив получается пустым. Для корректного сравнения алгоритмов нужен хотя бы один элемент.

- **Можно ли использовать проект как библиотеку?**  
  Внутренние модули (`sorts.py`, `sort_config.py`, `sort_func.py`) можно импортировать в другие проекты и, в частности, использовать в других Telegram‑ботах как вычислительное ядро (логика сортировки и замеров времени), реализуя вокруг них собственный интерфейс общения с пользователем.

- **Есть ли здесь консольная версия?**  
  В репозитории есть вспомогательный CLI‑интерфейс для разработки и отладки, но основным и поддерживаемым способом использования продукта является Telegram‑бот. Все ключевые сценарии для пользователей описаны именно для бота.
